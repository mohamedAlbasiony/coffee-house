# ☕ Coffee House - Full Landing Page

A modern, responsive, and interactive landing page for a coffee shop built using core web technologies (**HTML5, CSS3, JavaScript**).

![Coffee House Preview](Image/back.jpg)

---

## 🌟 Features

* 📱 **Fully Responsive:** Optimized for desktop, tablet, and mobile screens.
* 🛍️ **Interactive Product Counters:** Dynamic quantity controls for adding products to cart with strict validation (prevents negative counts).
* 🔐 **Dynamic Modals & Popups:**
  * Interactive Login Modal built dynamically using Vanilla JS DOM manipulation.
  * Image Lightbox Gallery modal to view high-res coffee images.
* 🎨 **Clean & Organized Code:** Structured using CSS Grid, Flexbox, and modern BEM/Semantic conventions.
* 🚀 **Fast Performance:** Pure JavaScript without heavy external libraries.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup structure.
* **CSS3:** Custom styles, Flexbox, CSS Grid, animations, and Responsive Design Media Queries.
* **JavaScript (ES6+):** Dynamic DOM Manipulation, Event Handling, and Modal Logic.
* **Font Awesome:** Iconography.
* **Google Fonts:** Custom typography (`Cairo` & `Kalam`).
